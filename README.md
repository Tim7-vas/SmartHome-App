# Умный дом (SmartHome)

Консольное приложение на C# (.NET), моделирующее систему управления устройствами умного дома. Проект разработан в среде **Visual Studio** с применением принципов ООП (абстрактные классы, наследование, полиморфизм и интерфейсы) и модели ветвления **Git Flow**

## Основной функционал
- Единое управление всеми устройствами умного дома (включение, выключение, вывод текущего статуса)
- Регулировка рабочих параметров устройств (яркость освещения, целевая температура, скорость вращения вентилятора)
- Формирование отчётов о событиях (фиксация движения камерой наблюдения)
- Настройка расписания автоматического включения и выключения устройств
- Подсчёт суточного энергопотребления (в кВт·ч) для всех энергозависимых приборов

## Структура проекта
```text
SmartHome/
├── Devices/
│ ├── SmartDevice.cs # Абстрактный базовый класс для всех устройств
│ ├── SmartLight.cs # Умная лампа (яркость, расписание, энергопотребление)
│ ├── SmartThermostat.cs # Умный термостат (температура, расписание, энергопотребление)
│ ├── SmartCamera.cs # Камера наблюдения (симуляция движения и отчётность)
│ ├── SmartLock.cs # Умный дверной замок (блокировка / разблокировка)
│ └── SmartFan.cs # Умный вентилятор (регулировка скорости от 0 до 5)
├── Interfaces/
│ ├── IAdjustable.cs # Интерфейс регулировки уровня параметра
│ ├── IReportable.cs # Интерфейс генерации краткого отчёта
│ ├── ISchedulable.cs # Интерфейс планирования времени работы
│ └── IEnergyConsumer.cs # Интерфейс расчёта потребления электроэнергии
├── Services/
│ └── DeviceManager.cs # Менеджер для централизованного управления устройствами
└── Program.cs # Точка входа и демонстрация работы системы
```

## Как открыть и запустить в Visual Studio
1. Склонируйте репозиторий:
```bash
git clone https://github.com
```
2. Откройте файл решения **`SmartHome.csproj`** (или `.sln`) в **Visual Studio**
3. Нажмите **`F5`** (или кнопку **Запуск** на верхней панели инструментов), чтобы скомпилировать и запустить приложение
